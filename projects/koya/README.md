# Koya project workspace

This directory contains project-specific evidence and production state. It is not reusable application source code.

## Sources of truth

- `source/` preserves original developer and marketing inputs.
- `production-assets/` classifies approved, generated and rejected derivatives with provenance.
- `video-production/` keeps prompts, locked manifests, provider responses and QA together.
- `operations/PIPELINE_STATUS.md` is the human-readable production status entry point.

`inbox/` contains unreconciled downloads. `workbench/` contains legacy temporary output. Neither location establishes approval, publication or release readiness.

Before property-video work, read `AGENTS.md` and `video-production/SEEDANCE_2_5_RULES.md`.
