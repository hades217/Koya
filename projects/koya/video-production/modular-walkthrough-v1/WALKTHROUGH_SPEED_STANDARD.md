# Apartment 106 Walkthrough — Physical Speed Standard

Status: mandatory for every remaining interior clip.

## Core rule

Shot duration is derived from real travel distance and action complexity. A provider's minimum generation duration is never treated as the final editorial duration.

## Movement targets

- Straight interior walking: 1.15–1.40 metres per second.
- Careful doorway crossing: 0.85–1.10 metres per second.
- A two-metre straight move: 1.5–1.9 seconds final screen time.
- A simple 90-degree turn from one fixed position: 0.7–1.0 seconds.
- One doorway approach and threshold crossing: 1.0–1.5 seconds.
- Opening hold: maximum 0.10 seconds unless orientation genuinely requires more.
- Ending settle: 0.15–0.25 seconds maximum.

## Seedance production rule

- Never write `exactly five seconds` as the intended visible duration for a two-metre move.
- If the provider requires a 5-second generation, either cover enough physical distance for five seconds at the target speed or retime the resulting physically valid motion locally before editorial use.
- A storyboard-to-storyboard interpolation must include a distance estimate and calculated target screen duration before paid submission.
- Reject floating, slow dolly motion even when topology is correct.
- No later piece may be submitted until its calculated distance, target speed and final screen duration are recorded in its manifest.
