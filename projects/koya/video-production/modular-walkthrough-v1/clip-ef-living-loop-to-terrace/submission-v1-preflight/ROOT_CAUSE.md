# Clip EF root-cause correction

## Confirmed failure

This result failed before Seedance inference: the provider received a structurally under-detailed reference MP4 whose visible checkpoints did not match the current route scene or the approved rendered storyboard V6.

The project did have render-level decoration studies. They were retained as review-only images because independently generated whole-room images cannot control a topology-sensitive video timeline. The production mistake was failing to rebuild those accepted designs inside the single deterministic scene before rendering the submitted reference video.

## Missing fixed-scene assets

- Plan-proportional Living/Dining width and clear circulation.
- Compact four-seat Dining table with four distinct chairs.
- One correctly scaled Kitchen island with sink, waterfall/stone treatment and seating.
- Complete north Kitchen joinery and appliances.
- Correct internal north TV/display wall below Bedroom 1, with the sofa facing it.
- Correct sofa scale and orientation without narrowing the route.
- Continuous full-height south and east glazing with the one physical east opening.
- Compact west-side MPR read without turning it into a bedroom or adding a column.
- Terrace depth and a final composition looking back through the same opening.

## New non-paid gate

Before any new Seedance task:

1. Rebuild all accepted geometry, furniture and finishes inside one deterministic scene.
2. Render a new local MP4 from that exact scene, not from another running preview or stale server.
3. Compare the MP4 at 0.00, 0.55, 1.25, 1.65, 2.15, 2.95, 3.35, 4.30, 5.35, 5.85, 6.35, 6.72, 7.15 and 7.95 seconds against the approved storyboard and official floor plan.
4. Require a visible MPR opening and Dining at the start, the correct TV wall during the panorama, true Living width, a physical threshold crossing and the final interior look-back.
5. Reject any mismatch before Seedance preflight or user approval.

No new paid generation is authorised by this document.
