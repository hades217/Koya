# Property video storyboard

Create a literal, evidence-controlled video plan before rendering.

- Specify aspect ratio, exact total duration, ordered scenes, on-screen copy, evidence, and transition intent.
- Do not imply physically continuous movement when the source assets cannot support it.
- A storyboard or authoring package is not an MP4, provider submission, or accepted video.
- Paid generation requires a separate reviewed package and explicit approval.
