# Koya

Private working repository for the Koya Residences off-the-plan property project in Brisbane.

The repository contains official source material, property research, Apartment 106 floor-plan analysis, generated production assets, storyboards, deterministic reference-video projects, Seedance submission records, QA evidence and the interactive apartment-tour application.

## Important directories

- `Koya/production-assets/` — classified official and generated project assets.
- `Koya/storyboards/` — storyboard and shot-planning material.
- `Koya/video-production/` — video workflow, prompts, task records, outputs and QA.
- `Koya/interactive-apartment-tour/` — interactive walkthrough application.
- `Koya/references/` — supporting references.

Read `AGENTS.md`, `CLAUDE.md` and `Koya/video-production/SEEDANCE_2_5_RULES.md` before changing property-video or Seedance work.

Large binary assets are stored through Git LFS. Rebuildable dependencies, framework caches and super-resolution experiments are intentionally excluded.
