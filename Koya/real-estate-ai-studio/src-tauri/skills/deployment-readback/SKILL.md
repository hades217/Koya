# Deployment read-back

Keep build, local preview, deployment, and public verification as independent states.

- Record the release version, included units, access mode, target, and timestamp.
- Do not call a local build public or deployed.
- Verify the public URL from the intended device class after publishing.
- Preserve the last verified release when a new deployment fails.
