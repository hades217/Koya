# Panorama production

Prepare equirectangular panorama work from accepted room evidence.

- Use a 2:1 equirectangular output and preserve the same camera position across generated segments.
- Validate seams, horizon, verticals, repeated objects, room topology, and mobile sharpness.
- Treat enhancement, stitching, browser runtime QA, and acceptance as separate steps.
- Never mark a panorama ready because the image provider completed successfully.
